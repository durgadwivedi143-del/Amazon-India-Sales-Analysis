# 🛒 Amazon India Sales Analysis

## 📌 Project Overview

This project focuses on analyzing Amazon India sales data using Python. The goal is to understand sales performance, identify trends, analyze product categories, and explore customer behavior.

## 🎯 Project Objectives

* Analyze overall sales and revenue.
* Identify top-performing products and categories.
* Study monthly sales trends.
* Analyze state-wise sales performance.
* Understand customer ratings and payment preferences.
* Examine order delivery status.
* Generate useful business insights and recommendations.

## ▶️ How to Run This Project

1. Download or clone this repository.
2. Keep the CSV file and Jupyter Notebook in the same folder.
3. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

4. Open Jupyter Notebook:

```bash
jupyter notebook
```

5. Open `Amazon_India_Sales_Analysis.ipynb` and run the cells.
